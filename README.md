# Data Science Jobs Salaries - Salary Analysis

Analise exploratoria de salarios em cargos de ciencia de dados. O notebook investiga diferencas por cargo, senioridade, ano, localizacao, tamanho da empresa e modelo de trabalho.

## Objetivo

Entender os principais fatores associados a variacao salarial em carreiras de dados e produzir insights comparaveis por dimensoes de negocio.

## O que o projeto demonstra

- Leitura e exploracao de base tabular de salarios.
- Transformacoes com Pandas para agrupamentos e comparacoes.
- Analise temporal de salarios entre 2020 e 2022.
- Comparacao por cargo, regiao, experiencia, tamanho da empresa e trabalho remoto.
- Visualizacoes com Plotly.
- Estrutura orientada por perguntas analiticas.

## Stack

- Python
- Pandas e NumPy
- Plotly
- Jupyter Notebook / Google Colab

## Arquivos

| Arquivo | Descricao |
| --- | --- |
| `Data_Science_Jobs_Salaries.ipynb` | Notebook principal com analise exploratoria de salarios. |

## Como executar

1. Abra o notebook no Google Colab ou Jupyter.
2. Disponibilize o arquivo `ds_salaries.csv` no caminho esperado ou ajuste a celula de leitura.
3. Execute as celulas em ordem.

## Pontos fortes para portfólio

O projeto mostra capacidade de transformar uma base simples em perguntas de negocio. Para entrevistas, ele ajuda a discutir analise exploratoria, agregacoes e comunicacao de insights.

## Limitações atuais

- O dataset nao esta versionado nem documentado no repositorio.

- Nao ha validacao dos dados de entrada.
- A analise ainda e mais descritiva do que engenheirada como pipeline.
- Falta conclusao executiva com principais achados e limitacoes.
